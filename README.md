# PostTrack — проект Почты России

Система мониторинга отправки и получения посылок и писем с разделением ролей отправителя, получателя и оператора отделения почтовой связи.


## 1. Назначение системы

* **Для отправителя:** оформление отправления и отслеживание посылки.
* **Для получателя:** отслеживание и получение посылки .
* **Для оператора ОПС:** приём отправлений, организация хранения на складе и выдача получателю.

## 2. Бизнес-логика

### Клиент пользователей

* **Кабинет отправителя:**
  * Калькулятор стоимости доставки с учётом габаритов, веса и способа доставки.
  * Получение штрихкода для сдачи отправления в отделении.
  * Таймлайн прохождения контрольных точек и ожидаемое время прибытия.
* **Кабинет получателя:**
  * Таймлайн прохождения контрольных точек и ожидаемое время прибытия.
  * Уведомления об изменении статуса посылки.
  * Получение кода для выдачи посылки в отделении.

### Клиент оператора

* **Модуль приёмки:**
  * Сверка веса с заявленным при оформлении.
  * Печать почтового ярлыка и перевод отправления в статус `ACCEPTED`.
* **Модуль хранения:**
  * Сканирование входящих отправлений.
  * Привязка отправления к физической ячейке кладовой: `Стеллаж X / Полка Y / Ячейка Z`.
* **Модуль выдачи:**
  * Поиск по трек-номеру или номеру телефона получателя.
  * Проверка цифрового кода подтверждения.
  * Отображение складской ячейки и закрытие отправления со статусом `DELIVERED`.

### Клиент службы доставки

* Изменение статуса отправления при прохождении этапов доставки.
* Изменение ожидаемого времени доставки при задержке.

## 3. Структура проекта

```text
app                       запуск 
shared                    общие доменные типы
modules/identity          пользователи и роли
modules/pricing           расчёт стоимости доставки
modules/shipment          жизненный цикл отправления
modules/tracking          отслеживание
modules/warehouse         хранение и выдача
infrastructure/postgres   подключение к постгресу
```
