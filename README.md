# PostTrack — упрощённый проект почты России.

Система мониторинга отправлений и получений посылок и писем с разделением ролей для отправителя, адресата и оператора отделения почтовой связи.


## 1. Назначение системы
* **Для отправителя:** онлайн оформление документов на отправку, отслеживание посылки.
* **Для получателя:** отслеживание посылки, получение посылки по уникальному идентификатору.
* **Для оператора ОПС:** организация хранения посылок на складе и их выдача получателю.


## 2. Бизнес логика

### Клиент пользователей

* **Кабинет отправителя:**
  * Калькулятор стоимости доставки - габариты `x, y, z`, вес посылки, выбор ускоренного или обычного.
  * Получение штрихкода для сдачи отправления в отделении.
  * Таймлайн прохождения контрольных точек и ожидаемое время прибытия.
* **Кабинет получателя:**
  * Таймлайн прохождения контрольных точек и ожидаемое время прибытия.
  * Push-уведомления об изменении статуса посылки.
  * Получение штрихкода для получения посылки в отделении.

### Клиент оператора

* **Модуль приёмки:**
  * Сверка фактического веса с заявленным в предзаказе.
  * Печать почтового ярлыка и перевод отправления в статус `ACCEPTED`.
* **Модуль сортировки и адресного хранения:**
  * Сканирование входящих отправлений.
  * Привязка номера к физической ячейке кладовой `Стеллаж X / Полка Y / Ячейка Z`.
* **Модуль выдачи:**
  * Поиск по трек-номеру или номеру телефона клиента.
  * Валидация цифрового кода подтверждения (ПЭП).
  * Автоматический вывод номера складской ячейки на экран оператора и закрытие заказа со статусом `DELIVERED`.

### Клиент службы доставки
 * Возможность изменения статуса доставки при прохождении этапов доставки.
 * Возможность изменить ожидаемое время доставки при задержке во времени доставки.
